Приведи в порядок runner.Run — им пользуется наш CLI на Linux и на Windows:

- аргументы с пробелами, кавычками и символами вроде `;`, `$`, `*` должны доходить до программы как есть;
- stdout и stderr нужны раздельно;
- ненулевой код выхода — не ошибка Run: код кладём в Result.ExitCode, а ошибку возвращаем, только если программу не удалось запустить или её прервали;
- при отмене ctx программа должна останавливаться, а Run — возвращать ошибку, для которой `errors.Is(err, ctx.Err())` истинно.

Обнови комментарий к Run под этот контракт.
