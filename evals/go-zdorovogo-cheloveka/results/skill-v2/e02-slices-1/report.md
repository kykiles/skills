КОРНЕВАЯ ПРИЧИНА:
Build и WithoutEmpty использовали append без создания копий, что приводило к общей памяти между несколькими slice'ами. Когда вторая команда вызывала append, она перезаписывала данные в той же памяти, которую использовала первая команда.

РЕШЕНИЕ:
- Build теперь копирует base в новый slice перед добавлением extra
- WithoutEmpty теперь использует make для создания нового slice вместо переиспользования входного array
