## statusapi: Исправления три жалобы клиента

### Выполненные изменения

**Файл: client.go**
Переписана функция `GetStatus()` с учётом контракта:

1. **Отмена контекста**: Используется `http.NewRequestWithContext(ctx, ...)` вместо `http.Client.Get()`, что позволяет HTTP-клиенту прервать запрос при отмене или дедлайне контекста.

2. **Ошибка при пустом статусе**: Добавлены проверки HTTP-статуса:
   - 404 → возвращает `ErrNotFound` (переменная ошибки для клиента)
   - Иной статус ≠ 200 → возвращает `&StatusError{Code: statusCode}`
   - 200 → разбирает и возвращает статус

3. **Утечки соединений**: Добавлен `defer resp.Body.Close()` на всех путях выхода (включая ошибки при разборе JSON). Это гарантирует закрытие соединения в пуле HTTP-клиента.

**Файл: client_test.go**
Добавлены четыре новых теста для проверки исправлений:

- `TestGetStatus_ContextCancellation`: Проверяет отмену по дедлайну (100ms задержка на сервере, 10ms таймаут на клиенте).
- `TestGetStatus_NotFound`: Проверяет, что 404 возвращает `ErrNotFound` (использует `errors.Is`).
- `TestGetStatus_UnexpectedStatus`: Проверяет, что 500 возвращает `*StatusError` с правильным кодом (использует `errors.As`).
- `TestGetStatus_ConnectionClosed`: Проверяет, что соединения закрываются при нескольких запросах.
