## Исправление пакета cmdargs

### Проблема
При вызове нескольких команд с общим профилем аргументов первая команда получала аргументы второй. Причина — функции пакета модифицировали подлежащие массивы входных срезов.

### Найденные ошибки
1. **Build()**: использовал `append(base, extra...)` напрямую, что писало в массив входного среза
2. **WithoutEmpty()**: использовал `args[:0]`, переиспользуя подлежащий массив входного среза

### Исправления
Файл `/tmp/claude-0/-home-user-skills/8db0c349-fe6f-5994-8f93-8a7d3bda3742/scratchpad/ws/skill-v3-2/cmdargs/cmdargs.go`:
- **Build()**: создается новый срез с правильной вместимостью перед append
- **WithoutEmpty()**: создается новый срез вместо переиспользования входного массива

Файл `/tmp/claude-0/-home-user-skills/8db0c349-fe6f-5994-8f93-8a7d3bda3742/scratchpad/ws/skill-v3-2/cmdargs/cmdargs_test.go`:
