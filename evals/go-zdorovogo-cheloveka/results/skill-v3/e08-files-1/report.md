## Исправлены две проблемы в функции CountMatches пакета logscan

### Проблемы и исправления:

1. **"too many open files" при работе с большим количеством логов**
   - Причина: `defer f.Close()` находился внутри цикла, что приводило к накоплению открытых файлов до конца функции
   - Решение: Вынес логику обработки файла в отдельную функцию `countFileMatches()`, где файл закрывается через `defer` перед возвратом
   - Результат: Файлы теперь закрываются после обработки каждого файла, а не в конце функции

2. **Результат меньше реального на некоторых больших логах**
   - Причина: Отсутствует проверка ошибки Scanner после цикла; буфер Scanner по умолчанию 64 КиБ не обрабатывает строки длиннее этого
   - Решение: 
     - Добавил проверку `sc.Err()` для перехвата ошибок переполнения буфера
     - Увеличил максимальный размер буфера Scanner до 10 МБ через `sc.Buffer()`
   - Результат: Теперь корректно обрабатываются файлы со строками длиннее 64 КиБ
