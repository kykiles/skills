Приведён в порядок runner.Run для поддержки CLI на Linux и Windows.

**Изменённые файлы:**
- runner.go: 33 новых строк, 7 удалённых (основная функция)
- runner_test.go: 75 новых строк (7 тестов вместо 1)

**Что исправлено:**

1. Удалена shell-инъекция: вместо `exec.Command("sh", "-c", ...)` используется `exec.CommandContext(ctx, name, args...)`. Аргументы с пробелами, кавычками, `;`, `$`, `*` теперь доходят до программы как есть.

2. Разделены stdout и stderr в отдельные буферы (вместо конкатенации в один).

3. Ненулевой код выхода больше не ошибка: код идёт в Result.ExitCode, ошибка только при неудаче запуска или отмене.

4. Добавлена правильная поддержка context:
   - Используется exec.CommandContext(ctx, ...)
   - При отмене контекста программа прерывается
   - Возвращается ошибка err такая, что errors.Is(err, ctx.Err()) истинно
   - Установлен WaitDelay для корректного завершения потомков

5. Обновлен doc-комментарий с полным описанием контракта.

- gofmt: оба файла отформатированы
- go test ./...: 7/7 тестов ✓ (echo, пробелы, stdout/stderr, exit code, canceled, not found, deadline)
- go vet ./...: ошибок нет
- go test -race ./...: гонок нет
- GOOS=windows go vet ./...: кросс-компиляция OK
