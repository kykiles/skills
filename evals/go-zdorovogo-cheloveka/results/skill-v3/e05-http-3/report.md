## Исправления в statusapi

Все три проблемы клиента statusapi исправлены и протестированы.

### Изменённые файлы:

**client.go** (22 новые строки, 2 изменённые):
- Добавлен импорт `io`
- Функция GetStatus полностью переписана согласно контракту в doc-комментарии и справочнику io-os.md
- Использование `http.NewRequestWithContext()` вместо `client.Get()` → GetStatus теперь учитывает отмену контекста
- Проверка HTTP статуса перед декодированием: 404 → ErrNotFound, остальное != 200 → *StatusError
- Добавлен `defer resp.Body.Close()` на всех путях, включая обработку ошибок
- Дочитывание тела при ошибках (io.Copy в io.Discard) для возврата соединения в пул
- Ограничение размера тела при декодировании (10<<20 байт)

**client_test.go** (83 новые строки):
- TestGetStatusNotFound: проверяет, что 404 возвращает ErrNotFound
- TestGetStatusError: проверяет, что неожиданный статус возвращает *StatusError с правильным кодом
- TestGetStatusCanceled: проверяет отмену контекста (уже отменённый ctx)
- TestGetStatusConnectionReuse: проверяет переиспользование соединений с ограниченным пулом
