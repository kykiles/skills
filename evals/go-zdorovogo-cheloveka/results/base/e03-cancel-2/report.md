## ProcessAll в пакете batch исправлен

### Исправленные проблемы:

**1. Утечка горутин после ошибок**
- Ранее при ошибке в fn горутины продолжали работать и накапливались
- Теперь использован sync.WaitGroup для отслеживания всех горутин

**2. Выполнение fn после возврата ProcessAll**
- Ранее fn вызывались даже после того как ProcessAll вернула ошибку/отмену
- Теперь создан внутренний контекст processCtx для сигнала отправителю остановиться

### Основные изменения в /tmp/claude-0/-home-user-skills/8db0c349-fe6f-5994-8f93-8a7d3bda3742/scratchpad/ws/base-2/batch/batch.go:

1. **sync.WaitGroup** - отслеживает завершение всех горутин (sender и workers)
2. **processCtx** - контекст для управления остановкой отправителя при ошибке
3. **Буферизация outcomes** - увеличена с workers до len(items) для предотвращения дедлоков
4. **Range-based loop** - замена цикла по счётчику на читающий из outcomes до закрытия
5. **Горутина-closer** - закрывает outcomes когда все workers завершены
6. **done канал** - гарантирует что все горутины завершены перед возвратом
