### Изменения

**1. Поддержка отмены контекста**
- Заменена вызов `httpClient().Get()` на `http.NewRequestWithContext(ctx, ...)` с `httpClient().Do(req)`
- Теперь метод правильно обрабатывает отмену контекста и дедлайны

**2. Корректная обработка HTTP-статусов**
- Добавлена проверка `resp.StatusCode` перед парсингом тела ответа
- HTTP 404 → возвращает `ErrNotFound` (как по контракту)
- Другие коды ошибок → возвращает `*StatusError` (как по контракту)
- Пустой статус без ошибки больше не происходит

**3. Закрытие соединений**
- Добавлена `defer resp.Body.Close()` для гарантированного закрытия ответа
- Предотвращаются утечки соединений под нагрузкой
