## Исправлены две проблемы с загрузкой конфигурации в svcconfig

### Проблема 1: Сервис не стартует с корректным файлом, ошибка `<nil>`
**Причина**: Функция `Load()` возвращала конфигурацию вместе с ошибкой валидации, не проверяя результат.
**Решение**: В `config.go` строки 47-50 добавлена проверка результата `validate()`. Теперь функция корректно возвращает `(nil, err)` если валидация не прошла.

### Проблема 2: Проверка `errors.Is(err, fs.ErrNotExist)` не срабатывает
**Причина**: Ошибки оборачивались с использованием `%v` вместо `%w`, что нарушало цепь ошибок.
**Решение**: В `config.go` строки 40 и 44 изменены на использование `%w`.

### Добавлены три новых теста в `config_test.go`:
1. **TestLoadValidConfig** - проверяет загрузку корректной конфигурации
2. **TestLoadMissingFile** - проверяет обработку отсутствующего файла и работу `errors.Is()` с `fs.ErrNotExist`
3. **TestLoadValidationError** - проверяет обработку ошибок валидации

### Результаты проверок:
✅ Все 4 теста пройдены успешно
✅ Тест 1: С корректным файлом конфигурации - сервис стартует с правильными параметрами
✅ Тест 2: При отсутствии файла - сервис запускается с настройками по умолчанию
✅ Тест 3: С невалидной конфигурацией - сервис выводит четкое сообщение об ошибке
