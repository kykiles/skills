Исправлены две проблемы с загрузкой конфигурации в svcconfig:

## Изменения:

### config.go (функция Load):

**Проблема 1 - "ошибка конфигурации: <nil>":**
- Причина: Load() возвращала ОБА значения (конфиг И ошибку) при ошибке валидации
- Решение: Строки 47-50 переписаны
  - Было: `return &cfg, validate(&cfg)`
  - Теперь: Проверяется результат валидации, возвращается `nil, err` при ошибке

**Проблема 2 - errors.Is(err, fs.ErrNotExist) не срабатывает:**
- Причина: fmt.Errorf() использовал %v, не сохраняя цепочку ошибок
- Решение: Строки 40, 44 изменены
  - Было: `fmt.Errorf("...: %v", path, err)`
  - Теперь: `fmt.Errorf("...: %w", path, err)` (сохраняет цепочку ошибок для errors.Is())
