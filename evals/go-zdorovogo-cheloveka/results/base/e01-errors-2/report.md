## Исправлены две проблемы с загрузкой конфигурации в svcconfig

### Проблема 1: "ошибка конфигурации: <nil>"
**Причина**: Функция `validate()` возвращала тип `*ValidationError`. Когда она возвращала `nil`, это создавал bug Go nil interface - nil указатель конкретного типа, возвращаемый из функции с типом возврата `error`, становится non-nil интерфейсом, содержащим nil pointer. При печати такого значения выводится `<nil>`.

**Решение**: Изменена сигнатура функции `validate()` в config.go (линия 59):
- Было: `func validate(c *Config) *ValidationError`
- Стало: `func validate(c *Config) error`

Это обеспечивает правильное возвращение nil error interface.

### Проблема 2: errors.Is(err, fs.ErrNotExist) не срабатывает
**Причина**: Ошибки оборачивались с помощью `fmt.Errorf(..., %v, ...)` вместо `%w`. Это нарушает цепь ошибок, и функция `errors.Is()` не может найти wrapped ошибку.

**Решение**: Изменены два места в Load() функции (config.go):
- Линия 40: Было `%v` → Стало `%w` в обработке ошибки os.ReadFile()
- Линия 44: Было `%v` → Стало `%w` в обработке ошибки json.Unmarshal()

Теперь ошибка правильно оборачивается, и `errors.Is()` может обнаружить `fs.ErrNotExist`.
