## Резюме проделанной работы

### Что изменено в runner.Run:

1. **Передача аргументов**: Изменена с `exec.Command("sh", "-c", ...)` на `exec.CommandContext(ctx, name, args...)`. Теперь аргументы передаются программе как есть, без интерпретации оболочкой. Пробелы, кавычки, $, *, ; и прочие символы доходят до программы неизменными.

2. **Разделение stdout/stderr**: Вместо единого буфера теперь используются отдельные buffers для stdout и stderr. Это обеспечивает корректное разделение выходов программы.

3. **Обработка кодов выхода**: Добавлена логика для извлечения и возврата кодов выхода через Result.ExitCode. Ненулевой код выхода больше не рассматривается как ошибка Run.

4. **Поддержка отмены контекста**: Использован exec.CommandContext для привязки контекста. При отмене ctx программа останавливается, и Run возвращает ctx.Err(), чтобы errors.Is(err, ctx.Err()) было истинно.

5. **Обновлен комментарий**: Подробный комментарий теперь полностью описывает контракт функции.
