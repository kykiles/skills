Исправлена критическая ошибка в пакете cmdargs.

Изменения:
1. Функция Build() - переписана на создание новой копии слайса вместо прямого append к base. Теперь каждый вызов получает независимый слайс.
2. Добавлен регрессионный тест TestProfileMultipleCommands, который проверяет что несколько команд с одним профилем работают независимо.

Проверки:
- Все 3 теста проходят успешно (включая новый регрессионный тест)
- Тесты запущены 3 раза с флагом -count=3 - результат consistent

Проблема была в том, что append() к слайсу с неиспользованной capacity модифицировал общий underlying array, вызывая конфликт аргументов между командами.
