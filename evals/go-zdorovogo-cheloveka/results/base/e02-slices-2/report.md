## Исправлены ошибки в пакете cmdargs

### Что было изменено:

**Файл: cmdargs.go**

1. **Функция `Build()`** - исправлена ошибка, где `append(base, extra...)` модифицировала исходный срез при наличии свободной емкости:
   - Было: `return append(base, extra...)`
   - Стало: создание нового среза с копированием значений

2. **Функция `WithoutEmpty()`** - исправлена ошибка, где `args[:0]` создавала представление исходного массива:
   - Было: `out := args[:0]` (модифицирует исходный массив)
   - Стало: `out := make([]string, 0, len(args))` (новый независимый срез)

**Файл: cmdargs_test.go**

- Добавлен новый тест `TestProfileMultipleCommands()`, который воспроизводит исходную ошибку: когда несколько команд используют один Profile, первая команда получала аргументы второй

### Результаты проверок:

✅ **go test -v**: Все 3 теста пройдены (включая новый тест)
✅ **go test -count=5**: Все тесты пройдены 5 раз подряд (консистентность)
✅ **go test -race**: Никаких проблем с конкурентностью
✅ **go test -cover**: 100% покрытие кода
✅ **go fmt**: Код отформатирован по стандартам Go

Проблема полностью устранена. Теперь каждый вызов `Command()` получает свой независимый срез аргументов, и аргументы разных команд не пересекаются.
