Исправлена проблема в пакете cmdargs, где аргументы разных команд перемешивались при использовании общего профиля.

## Что изменено

Исправлены две функции в файле `.../ws/base-1/cmdargs/cmdargs.go`:

1. **Функция Build()**: теперь создаёт новый слайс перед добавлением элементов вместо использования append() напрямую. Это предотвращает переиспользование основного массива.
   - Было: `return append(base, extra...)`
   - Стало: Создание нового слайса с нужной capacity и копирование элементов base

2. **Функция WithoutEmpty()**: теперь создаёт новый слайс вместо использования slice re-slicing (args[:0]), которое переиспользовало исходный массив.
   - Было: `out := args[:0]`
   - Стало: `out := make([]string, 0, len(args))`
