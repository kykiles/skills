Функция `format_report` в `/tmp/ws/base/r04-1/src/report.rs` была рефакторирована с выделением общей логики в отдельные функции:

1. **Новые вспомогательные функции**:

2. **Добавлен тип алиас**: `type SourceMap<'a> = BTreeMap<&'a str, Vec<&'a Entry>>` для упрощения сигнатур функций.
