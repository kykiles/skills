Исправлены 3 критические уязвимости в библиотеке `pak`:

**Проблемы:**
1. Истощение памяти (OOM): Vec::with_capacity(count) из недоверенного входа мог выделить гигабайты
2. Переполнение при чтении таблицы: pos += ENTRY_LEN без проверок
3. Потеря данных: u64 offset приводился к u32, теряя информацию

**Исправления в /tmp/ws/base/r02-3/src/lib.rs:**
- Добавлена проверка: count ≤ 65536, иначе ошибка TooManyEntries
- Использованы checked_add() для всех операций сложения (pos, offset+len)
- Entry::offset изменён с u32 на u64 для сохранения полной точности
- Новая ошибка InvalidOffset для обнаружения переполнений
- Добавлены 6 новых тестов безопасности
