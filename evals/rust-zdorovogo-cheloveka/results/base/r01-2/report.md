## Что изменено

В файле `/tmp/ws/base/r01-2/src/lib.rs`:

1. **Добавлен новый вариант ошибки** `ConfigError::InvalidValue` с полями:
   - `line: usize` — номер строки конфига
   - `key: String` — название ключа
   - `value: String` — значение, которое не удалось спарсить
   - `reason: String` — описание проблемы

2. **Обновлен Display для ConfigError** — теперь вывод InvalidValue содержит все детали: `"строка {line}: ключ `{key}` = `{value}`: {reason}"`

3. **Заменены все `.unwrap()` на обработку ошибок**:
   - `port` (u16): "должно быть число от 0 до 65535"
   - `timeout_ms` (u64): "должно быть число (миллисекунды)"
   - `verbose` (bool): "должно быть true или false"

4. **Добавлены тесты**:
   - `rejects_invalid_port()` — проверка ошибки при `port = 80o`
   - `rejects_invalid_timeout_ms()` — проверка ошибки при `timeout_ms = abc`
   - `rejects_invalid_verbose()` — проверка ошибки при `verbose = maybe`
   - `error_message_includes_details()` — проверка полноты сообщения об ошибке
