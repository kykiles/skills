## Исправлены критические уязвимости безопасности в библиотеке `pak`

**Изменённые файлы:** `/tmp/ws/skill-v1/r02-1/src/lib.rs`

### Проблемы и исправления

1. **Паника при переполнении и OOM (инцидент 1-2)**
   - Было: `as usize` без лимита на `count` из заголовка → `Vec::with_capacity(count)` вызывал OOM на 12-байтных файлах
   - Исправлено: добавлена константа `MAX_RECORDS = 65536`, используется `TryFrom` с проверкой лимита (строка 69-72)

2. **Переполнение при чтении таблицы (инцидент 1)**
   - Было: `pos += ENTRY_LEN` без проверки может переполниться
   - Исправлено: использован `checked_add` (строка 84)

3. **Некорректное чтение offset из таблицы (инцидент 3)**
   - Было: срез `raw[8..]` может быть не ровно 4 байта; прямое приведение `as u32` без проверки
   - Исправлено: явная индексация `raw[8..12]` (строка 81) и `TryFrom` с ошибкой (строка 82)

4. **Переполнение при проверке границ (инцидент 1-3)**
   - Было: `entry.offset + entry.len` может переполниться, возвращая ложно положительный результат
   - Исправлено: использован `checked_add` с обработкой ошибки (строка 89-92)

5. **Переполнение при доступе в `get()` (инцидент 3)**
   - Было: `start + entry.len as usize` может переполниться, панихе с `index out of bounds`
   - Исправлено: `checked_add` и безопасный `.get()` вместо индексации (строка 114-115)
