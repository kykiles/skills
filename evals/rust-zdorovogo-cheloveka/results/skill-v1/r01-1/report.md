## Исправлена обработка ошибок парсинга конфига relay

### Что изменено в `/tmp/ws/skill-v1/r01-1/src/lib.rs`:

1. **Добавлен новый вариант ошибки** `ConfigError::InvalidValue` с полями:
   - `line: usize` — номер строки конфига
   - `key: String` — название ключа
   - `value: String` — значение, которое не удалось распарсить
   - `source: String` — описание ошибки парсинга

2. **Обновлен вывод ошибки** в `Display`:
   - Выводит понятное сообщение: "строка {line}: `{key} = {value}` — {source}"

3. **Заменены три `unwrap()`** на обработку ошибок `match`:
   - `port` (парсинг в u16)
   - `timeout_ms` (парсинг в u64)
   - `verbose` (парсинг в bool)

4. **Добавлены три новых теста** для проверки обработки ошибок парсинга каждого ключа

### Результаты:

**До исправления:**
- Опечатка `port = 80o` → паника: `thread 'main' panicked at src/lib.rs:95:51: called 'Result::unwrap()' on an 'Err' value: ParseIntError { kind: InvalidDigit }`

**После исправления:**
- Опечатка `port = 80o` → понятная ошибка: `ошибка: строка 2: 'port = 80o' — invalid digit found in string` с выходом код 2
- Остальные ошибки парсинга (timeout_ms, verbose) обрабатываются аналогично с информацией о строке, ключе и причине
- Существующие ошибки (отсутствие файла, неизвестный ключ) продолжают работать как раньше
