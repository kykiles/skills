## Что изменено
В /tmp/ws/skill-v1/r05-3/src/lib.rs:
- Удалена функция requests(), копировавшая весь лог в памяти
- Удалена структура Request — теперь используются кортежи
- parse_line() переделана на принятие &str вместо String, парсит поля без промежуточного вектора
- top_paths() обрабатывает строки напрямую через log.lines(), использует into_iter() без дополнительных клонирований
- bytes_by_status() обрабатывает строки напрямую, парсит только нужные поля, не парсит пути

## Результат
Память теперь зависит только от числа уникальных путей и статус-кодов, а не от размера лога. Устранены множественные выделения памяти на каждую строку и копирование всего лога в промежуточный вектор. Публичный API не изменился.
