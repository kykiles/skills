Улучшена обработка ошибок конфигурации в relay.

Что изменено (src/lib.rs):
- Добавлен новый вариант ConfigError::InvalidValue с номером строки, ключом и описанием проблемы
- Заменены три unwrap() на map_err() с использованием оператора ? для ключей port, timeout_ms и verbose
- Каждый ключ теперь возвращает специфичное сообщение об ошибке с описанием формата значения
- Обновлена документация функции parse() для отражения нового типа ошибки
- Добавлены три новых теста для проверки некорректных значений

Примеры исправленных ошибок:
- port = 80o → "строка 1: некорректное значение ключа 'port': ожидается число от 0 до 65535"
- timeout_ms = abc → "строка 1: некорректное значение ключа 'timeout_ms': ожидается целое число миллисекунд"  
- verbose = maybe → "строка 1: некорректное значение ключа 'verbose': ожидается 'true' или 'false'"

Проверки:
- cargo build --offline: успешно
- cargo test --offline --lib: 5 тестов пройдены
- cargo fmt: успешно
- cargo clippy: нет ошибок
- Exit code 2 сохраняется для всех ошибок конфигурации
