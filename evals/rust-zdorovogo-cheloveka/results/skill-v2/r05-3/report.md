Оптимизация `logtop` завершена успешно.

**Ключевые изменения в src/lib.rs (22 добавления, 28 удалений):**

1. Структура Request теперь использует lifetime и хранит `&'a str` вместо `String`
2. parse_line теперь принимает `&str`, использует итератор вместо Vec
3. Удалена промежуточная функция requests() 
4. top_paths: HashMap<&str, usize> вместо HashMap<String, usize>
5. bytes_by_status: работает напрямую с log.lines()

**Результат:**
- Память зависит только от числа уникальных путей/кодов, не от размера лога
- Устранена массовая фрагментация malloc/free (несколько вызовов на строку)
- Публичный API не изменился
