Оптимизирована программа logtop для снижения использования памяти:

**Основные изменения в /tmp/ws/skill-v2/r05-2/src/lib.rs:**

1. parse_line: изменена сигнатура с String на &str, убран Vec<String> для полей - используется итератор split_whitespace()
2. Удалена вспомогательная функция requests - убраны промежуточные Vec<String> для всех строк и Vec<Request>
3. top_paths и bytes_by_status: обработка строк напрямую log.lines(), использование into_iter() вместо iter().map().clone()

**Результат:**
- Память теперь зависит только от числа уникальных путей и кодов ответа, не от размера логов
- O(log_size) выделений памяти сокращено до O(num_unique_paths)
- Исключены множественные клонирования строк пути при каждой обработке строки логов
