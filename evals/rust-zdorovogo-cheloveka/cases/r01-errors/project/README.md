# relay

Сервис-ретранслятор. Конфигурация — файл со строками `ключ = значение`:

```text
# комментарий
listen = 0.0.0.0
port = 8080
timeout_ms = 30000
verbose = false
```

Запуск: `relay [путь к конфигу]`, по умолчанию `relay.conf`. При ошибке конфигурации сервис печатает причину и завершается с кодом 2.
