# Тесты

**Принцип:** тест проверяет наблюдаемое поведение и падает с понятным сообщением.

- По умолчанию сравнивай объект целиком: `assert_eq!(parsed, Config { port: 8080, host: "localhost".into() })`, а не поле за полем. Так новое поле не выпадет из проверки, а diff в сообщении покажет всё расхождение. Если часть полей несущественна для контракта или нестабильна (время, сгенерированный идентификатор, порядок без гарантии), проверяй нужные свойства и явно назови, что не сравнивается. Если тип не реализует `PartialEq` и `Debug`, добавь `derive`, когда это естественно для типа; публичному типу — с учётом того, что это расширяет его API.
- Проверяй поведение, которое может сломаться: не тестируй значения констант и статические таблицы, а для удалённой логики не пиши тест на её отсутствие.
- Передавай зависимости от окружения параметром. Тесты работают параллельно в потоках одного процесса, поэтому изменение переменных окружения в одном тесте влияет на соседние; в edition 2024 `std::env::set_var` и `remove_var` к тому же `unsafe`. Читай окружение на границе программы и передавай значение в тестируемую функцию.
- Тестовые помощники держи в тестовом модуле или в `tests/`; основная реализация не получает функций «только для тестов». Перед тем как написать помощник, проверь, нет ли готового в проекте.

```rust
#[derive(Debug, PartialEq)]
struct Config {
    port: u16,
    host: String,
}

fn parse_config(text: &str) -> Option<Config> {
    let (host, port) = text.split_once(':')?;
    Some(Config { port: port.parse().ok()?, host: host.to_owned() })
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn parses_host_and_port() {
        assert_eq!(
            parse_config("localhost:8080"),
            Some(Config { port: 8080, host: "localhost".to_owned() })
        );
    }
}
```

**Проверка выбора:** удали мысленно проверяемую строку кода — упадёт ли тест? Если нет, он проверяет не то. Добавь поле в структуру — заметит ли тест, что его значение неверно? Если нет и поле входит в контракт, сравни объект целиком.
